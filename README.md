# SolidWorks – Mechanical Design Projects

## Overview
This repository contains a collection of mechanical design projects developed using **SolidWorks** as part of my CAD learning journey.

The projects demonstrate practical experience in 3D part modeling, mechanical components design, and assembly modeling.

## Projects

### 1. CSWA Sample Exam – Assembly 1

A mechanical assembly exercise based on a CSWA sample exam.

**Files included:**
- `Assem1.SLDASM` – Main assembly.
- `chain_link.SLDPRT` – Chain link component.
- `long_pin.SLDPRT` – Long pin component.
- `short_pin.SLDPRT` – Short pin component.
